部署成网址（三种方式，均无需后端）

1
最省事：拖到静态托管
把本文件改名 index.html，拖进 Netlify Drop / Cloudflare Pages / Vercel，几秒后得到一个 https 链接，手机直接打开。文件是纯前端、无 CDN 依赖，断网也能用。

有 GitHub：GitHub Pages
新建仓库 → 上传 index.html → Settings → Pages → Deploy from branch (main / root) → 得到 https://<用户名>.github.io/<仓库名>/。
3
只想局域网给手机用
电脑与本机同一 Wi-Fi，在文件目录执行 python -m http.server 8000，手机访问 http://电脑局域网IP:8000。注意 Windows 防火墙放行。
微信/QQ 内置浏览器可能限制本地文件与部分 API；正式使用请用系统浏览器（Safari / Chrome / Edge），并「添加到主屏幕」。本工具不含任何后端与账号，配置只存本机 localStorage 与分享链接的 hash 中。

算法与口径

腰射：S_B = S_A × PPI_A / PPI_B（360° 等距）。
开镜：S_B(镜) = S_A(镜) × PPI_A/PPI_B × θ(c, FOV_B镜)/θ(c, FOV_A镜)，θ(c,f) = arctan(c·tan(f/2))，c 为 MDV 系数。
陀螺仪：G_B = G_A × tan(FOV_B/2)/tan(FOV_A/2)（无 PPI）。
镜内 FOV：FOV镜 = 2·arctan(tan(FOV_base/2)/zoom)。
数据口径：荣耀 200 Pro 437PPI/120Hz；Y700 2025 343PPI/165Hz；灵敏度推荐值 125/125/125/65 与 MDV 1.33 来自社区攻略，非官方。
本工具是估算器，最终以靶场实测微调 0.1 为准。
